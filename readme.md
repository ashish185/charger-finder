**Branch Rules**
"The branch name must start with one of these words: feature, bugfix, hotfix, release, docs, chore, refactor, or test, followed by /, followed by one or more lowercase letters, numbers, dots, underscores, or hyphens, and nothing else."

- Examples

```
feature/login
bugfix/payment
hotfix/crash
```

**Formatting**

- Eslint
- Prettier
