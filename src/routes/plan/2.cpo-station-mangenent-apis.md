## 2. Station Management

### 2.1 Create Station

`POST /stations`

```json
// Request
{
  "name": "string",
  "address": "string",
  "location": { "lat": 17.4123, "lng": 78.4456 },
  "operatingHours": { "open": "06:00", "close": "23:00", "is24x7": false },
  "amenities": ["restroom", "food", "parking", "wifi"],
  "bookingRules": { "advanceBookingMinutes": 30, "cancellationWindowMinutes": 10 },
  "paymentSupport": ["upi", "card", "wallet"],
  "supportContact": { "name": "string", "phone": "string" }
}

// Response 201
{
  "success": true,
  "data": {
    "stationId": "stn_uuid",
    "status": "draft",          // draft -> pending_review -> live
    "createdAt": "timestamp"
  }
}
```

### 2.2 List Stations (own portfolio)

`GET /stations?status=&city=&page=&limit=`

```json
// Response 200
{
  "success": true,
  "data": {
    "stations": [
      {
        "stationId": "stn_uuid",
        "name": "string",
        "status": "live | draft | delisted | maintenance",
        "trustScore": 92,
        "lastAcknowledgedAt": "timestamp",
        "chargerCount": 4
      }
    ],
    "pagination": { "page": 1, "limit": 20, "total": 8 }
  }
}
```

### 2.3 Get Station Detail

`GET /stations/{stationId}` → full static + dynamic payload (station object as in 2.1 plus current status fields from Section 4/5).

### 2.4 Update Station Metadata

`PUT /stations/{stationId}` — same body shape as 2.1 (partial allowed via `PATCH /stations/{stationId}`).

### 2.5 Delete / Deactivate Station

`DELETE /stations/{stationId}` → soft-delete, sets status `delisted`.

### 2.6 Add Charger to Station

`POST /stations/{stationId}/chargers`

```json
// Request
{
  "connectorType": "CCS2 | CHAdeMO | Type2_AC | Bharat_AC001 | Bharat_DC001",
  "maxPowerKw": 30,
  "vehicleCompatibility": ["2W_scooter", "2W_motorcycle", "3W", "4W"],
  "pricePerKwh": 18.5,
  "pricePerMinute": null
}

// Response 201
{
  "success": true,
  "data": { "chargerId": "chg_uuid", "status": "available" }
}
```

### 2.7 Update / Remove Charger

`PUT /stations/{stationId}/chargers/{chargerId}` — same body as 2.6.
`DELETE /stations/{stationId}/chargers/{chargerId}` → `204`.

### 2.8 Update Pricing

`PUT /stations/{stationId}/chargers/{chargerId}/pricing`

```json
// Request
{ "pricePerKwh": 19.0, "pricePerMinute": null, "effectiveFrom": "timestamp" }
// Response 200 — triggers immediate reflection on driver app (Section 8, Flow 4)
{ "success": true, "data": { "chargerId": "chg_uuid", "pricePerKwh": 19.0, "updatedAt": "timestamp" } }
```

### 2.9 Update Operating Hours / Amenities

`PUT /stations/{stationId}/operating-hours`
`PUT /stations/{stationId}/amenities`
(bodies mirror the relevant fields in 2.1)
