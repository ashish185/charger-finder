- Inject dependencies through constructors instead of creating classes internally

Example:

```js
class StationService {
  constructor(stationRepository) {
    this.stationRepository = stationRepository;
  }
}
```

Use:

- `IStationRepository` → repository contract
- `StationRepository` → Mongoose implementation
- `MockStationRepository` → unit testing

Keep controllers thin:

- Receive request
- Call service
- Return response

Apply patterns only where useful:

- Repository Pattern
- Dependency Injection
- Strategy Pattern (pricing)
- Factory Pattern (pricing creation)

Ensure the design supports easy unit testing by replacing real dependencies with mocks without changing business logic.

Do not over-engineer. Keep the existing functionality and coding style.
